# Observations

Instrument data products, calibration, recovery, integrity checks, and
cross-instrument preparation used by the manuscript.

- `data/`: tracked input descriptions and compact manifests.
- `methods/`: current observation and calibration methods.
- `results/`: canonical observation products.
- `figures/`: observation-specific figure producers and review sources.
- `tests/`: subject-specific scientific checks.
- `studies/`: historical or focused investigations, hidden behind this subject.
